# Kanban Lite – Interactive Task Board

A responsive task board built with plain HTML5, CSS3 and JavaScript (ES6+). No frameworks.

🔗 **Live demo:** https://galtarchik.github.io/Interactive-Task-Board/

## Features
- Three columns: **To Do**, **In Progress**, **Completed**
- Add tasks with title, description, category and priority
- Move tasks with buttons or **drag and drop**
- Delete tasks
- Tasks are saved in `localStorage`, so they survive a page refresh
- Priority colours: High = red, Medium = amber, Low = green
- Search by title and filter by category
- **Dark mode** toggle (remembers your choice)
- **Task counter** with active vs. completed tasks
- Responsive layout for mobile, tablet and desktop

## Files
- `index.html` – page structure
- `style.css` – styling, themes and responsive rules
- `script.js` – state, storage, rendering and drag & drop
